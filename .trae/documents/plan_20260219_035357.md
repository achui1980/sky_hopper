我将为您的游戏设计并实现一个轻量级、可扩展的多语言系统。

**核心设计思路**

1. **数据与逻辑分离**：创建一个独立的语言包文件（`i18n.js`），集中管理所有中英文本。
2. **HTML 标记化**：在 `index.html` 中为需要翻译的元素添加 `data-i18n` 属性。
3. **动态加载与切换**：

   * 游戏启动时自动检测浏览器语言（或默认英语）。

   * 提供一个 `LanguageManager` 类，负责加载语言包并更新 DOM 元素和 Phaser 游戏内的动态文本。

   * 在主菜单添加一个“语言切换”按钮。

**具体实施计划**

1. **创建语言包文件 (`js/i18n.js`)**

   * 定义 `en` 和 `zh` 两个对象。

   * 包含所有 UI 文本（标题、按钮、说明）和游戏内动态文本（命运卡片标题、描述模板）。

2. **修改 HTML (`index.html`)**

   * 为所有包含文本的标签添加 `data-i18n="key"` 属性。

   * 在 `#ui-layer` 中添加一个语言切换按钮（例如：🌐）。

3. **创建语言管理器 (`js/managers/LanguageManager.js`)**

   * 实现 `setLanguage(lang)` 方法：更新 HTML 元素的 `textContent`。

   * 实现 `getText(key, params)` 方法：供 Phaser 场景获取带参数的动态文本（如分数、百分比）。

   * 处理本地存储，记住用户的语言选择。

4. **集成到游戏逻辑**

   * **`main.js`**: 初始化 `LanguageManager` 并挂载到全局或 `game` 对象上。

   * **`PlayScene.js`**:

     * 修改 `updateHighScoreDisplay` 等 UI 更新方法，使用 `LanguageManager.getText()` 获取文本。

     * 修改命运卡片（Fate Card）的生成逻辑，从语言包获取标题和描述模板。

5. **样式调整 (`style.css`)**

   * 为语言切换按钮添加样式。

   * 针对中文可能需要的字体调整（如使用系统默认无衬线字体即可，通常无需额外 Web Font）。

**预期效果**

* 玩家点击语言按钮可即时切换界面语言。

* 游戏内的提示、命运卡片描述、结束画面等均会自动更新为对应语言。

* 支持后续轻松添加更多
