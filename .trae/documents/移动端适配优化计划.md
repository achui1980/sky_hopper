# 移动端适配计划 (含虚拟按键与暂停优化)

根据您的要求，我们将加入虚拟按键并调整触控逻辑。

## 1. 添加虚拟按键 UI (index.html & style.css)
在游戏界面层之上添加可视化的虚拟按键，仅在移动端（小屏幕）显示。
- **HTML**: 添加 `#mobile-controls` 容器，包含左箭头 (`#btn-left`) 和右箭头 (`#btn-right`) 按钮。
- **CSS**:
    - 将按钮固定在屏幕底部的左右两侧。
    - 设置半透明样式，避免遮挡太多游戏画面。
    - 使用媒体查询 `@media (max-width: 768px)` 确保只在移动设备显示。
    - 确保按钮支持多点触控（不会相互冲突）。

## 2. 实现交互逻辑 (PlayScene.js)
修改输入监听逻辑，移除旧的全屏左右点击判定，改为：
- **虚拟按键控制**：
    - 监听左/右按钮的 `touchstart` / `mousedown` 事件 -> 设为移动状态。
    - 监听 `touchend` / `mouseup` / `mouseleave` 事件 -> 停止移动。
    - *优化*：同时支持点击按钮周边区域，增大触控热区。
- **中央区域暂停**：
    - 在场景的 `pointerdown` 事件中检测坐标。
    - 如果触控点 X 坐标在屏幕中间区域（例如 35% - 65% 宽度范围内），则触发 `togglePause()`。

## 3. 视口优化 (style.css)
- 保持原计划，使用 `min-height: 100dvh` 修复移动端浏览器地址栏导致的高度跳动问题。

## 执行步骤
1.  修改 `index.html` 添加按钮元素。
2.  修改 `style.css` 添加按钮样式和视口修复。
3.  修改 `js/scenes/PlayScene.js` 实现新的输入控制逻辑。
