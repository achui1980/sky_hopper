# UniApp 多端发布与微信小程序适配方案

您的需求是使用 UniApp 实现 PC、Android、鸿蒙发布，并希望支持微信小程序。
针对微信小程序的特殊限制（不支持本地 HTML），我们需要采用 **“双轨制”** 策略：

1.  **App/鸿蒙端**：使用 **本地 HTML 集成**（`/hybrid/html`），确保离线体验和高性能。
2.  **微信小程序端**：使用 **在线 WebView 加载**（`https://`），因为小程序强制要求业务域名。

## 1. 资源准备与本地化
- **下载 Phaser**：将 `phaser.min.js` 下载到本地，确保 App 端完全离线运行。
- **项目部署**：虽然我们主要做本地集成，但为了支持微信小程序，您后续需要将游戏部署到 HTTPS 服务器（如 Vercel/GitHub Pages）。我将协助您准备好部署所需的文件结构。

## 2. 创建 UniApp 项目结构
我们将构建一个智能的 UniApp 项目，它会根据运行平台自动切换加载方式。
- **目录结构**：
    - `uni_wrapper/` (UniApp 项目根目录)
        - `hybrid/html/sky_hopper/` (存放游戏源码，供 App 端使用)
        - `pages/index/index.vue` (主页面，包含智能判断逻辑)
        - `manifest.json` (多端配置)

## 3. 编写智能加载逻辑 (`index.vue`)
在 Vue 页面中使用条件编译 (`#ifdef`) 来区分平台：
- **`#ifdef APP-PLUS`** (App/鸿蒙)：`<web-view src="/hybrid/html/sky_hopper/index.html">`
- **`#ifdef MP-WEIXIN`** (微信小程序)：`<web-view src="https://您的域名.com">` (提示用户需替换为实际域名)
- **`#ifdef H5`** (PC/Web)：直接嵌入或 iframe 加载。

## 4. 输出成果与文档
- **代码**：生成完整的 `uni_wrapper` 项目文件夹。
- **文档**：`UNIAPP_GUIDE.md`，包含：
    - 如何使用 HBuilderX 运行和打包 App。
    - 如何配置微信小程序的业务域名。
    - 鸿蒙系统的打包说明。

## 执行步骤
1.  **下载依赖**：下载 `phaser.min.js` 并更新游戏 HTML。
2.  **生成项目**：创建 UniApp 项目结构，复制游戏文件到 `hybrid` 目录。
3.  **编写逻辑**：实现 `index.vue` 的多端适配逻辑。
4.  **编写文档**：生成操作指南。
